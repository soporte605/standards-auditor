# Seguridad

El auditor lee archivos del proyecto que analiza y genera reportes HTML; no ejecuta su código ni hace peticiones de red.

## Reportar una vulnerabilidad

No abras un issue público. Usa [Reportar una vulnerabilidad](https://github.com/soporte605/standards-auditor/security/advisories/new) en la pestaña _Security_ del repositorio. Incluye la versión, los pasos para reproducirla y su impacto. Se responderá lo antes posible y se coordinará la corrección y su publicación en una versión nueva.

Se consideran vulnerabilidades, entre otras: escape de HTML en los reportes, lectura de archivos fuera del proyecto mediante rutas o packs, y ejecución de código al cargar una configuración.

## Versiones con soporte

Solo la última versión publicada recibe correcciones.
