# Paquetes previstos

Esta carpeta reserva el lugar de los paquetes oficiales. No hay paquetes ejecutables todavía.

Cada paquete tendrá identidad, versión SemVer, compatibilidad con el motor, reglas y documentación. Una regla declarará identificador estable, detector soportado, severidad predeterminada, parámetros, explicación y ejemplos válidos e inválidos.

Los primeros dominios serán documentación, versionado, changelog y pruebas de Angular. Los equipos podrán distribuir paquetes locales; la instalación remota se añadirá después.
